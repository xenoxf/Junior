## Glenker
- **Año / Estado:** 2026 · En producción
- **Propósito:** Ofrecer una interfaz web completa para gestionar agentes de código y revisar su trabajo, accesible desde el navegador.
- **Arquitectura:** Monorepo con backend Express 5 (API REST) y frontend React 19 sobre Vite 7, ambos en TypeScript, con Tailwind CSS 4 para la interfaz.
- **Tecnologías / Librerías:** TypeScript, Express 5, React 19, Vite 7, Tailwind CSS 4
- **Enlace:** github.com/xenoxf/Glenker · glenker.vercel.app

## LearnYos
- **Año / Estado:** 2026 · En producción
- **Propósito:** Plataforma de aprendizaje online para ayudar a estudiantes a preparar exámenes mediante práctica de preguntas, flashcards y seguimiento de progreso.
- **Arquitectura:** Frontend Next.js 14 (React 18) con Tailwind CSS 3 que consume la API REST del backend Klerk.
- **Tecnologías / Librerías:** Next.js 14, React 18, Tailwind CSS 3, TypeScript
- **Enlace:** github.com/xenoxf/learnyos-x2 · learnyos.vercel.app

## Klerk
- **Año / Estado:** 2026 · En producción (actividad más reciente: agosto 2026)
- **Propósito:** Servir y persistir los datos de LearnYos (exámenes, flashcards y progreso de estudio) desde el servidor.
- **Arquitectura:** API en TypeScript con capa de acceso a datos mediante TypeORM (ORM), separando la lógica de persistencia del frontend. Licencia AGPL-3.0.
- **Tecnologías / Librerías:** TypeScript, TypeORM
- **Enlace:** github.com/xenoxf/klerk
